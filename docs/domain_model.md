## 2. 4時間ウィンドウ仕様
- 指定中の表示範囲（例: 1週間、1ヶ月など）において、測定データのタイムスタンプから「時刻」のみを抽出し、ヒストグラムを作成する。
- スライディングウィンドウを用いて、測定点が最も多い連続する4時間を抽出する。
- 季節による変動を吸収し、その期間において最も測定密度の高い時間を自動的に決定する。

## 3. 異常点除去（$2\sigma$）
- 体脂肪率、骨格筋率、体脂肪量、骨格筋量の4項目を対象とする。
- 直近の移動平均を算出し、平均から $2\sigma$ 以上外れたデータを「異常値」としてフラグ付けし、グラフ描画や4時間ウィンドウ算出時に除外・またはマーキングする。
